# jOpenSpace
Web for the jOpenSpace - developers non-conference located in Czech Republic.

## Local build

The site is built by GitHub Pages (Jekyll). To build or preview it locally you only need Docker:

```sh
./jekyll.sh serve    # preview on http://localhost:4000 with live reload
./jekyll.sh build    # generate the site into ./_site
./jekyll.sh update   # upgrade gems to the latest github-pages release
```
